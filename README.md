# 🎯 Number Guessing Game in C++

A simple and interactive **Number Guessing Game** developed using C++. The computer generates a random number between 1 and 100, and the player has to guess the correct number.

The game provides hints like **"Too High"** or **"Too Low"** after each guess to help the player reach the correct answer. It also tracks the number of attempts, displays the final result, and allows the player to play again.

### ✨ Features
- Random number generation (1–100).
- Interactive user input.
- Helpful hints: Too High / Too Low.
- Tracks the number of attempts.
- Displays the final score.
- Replay option to start a new game.

### 🛠️ Concepts Used
- C++ Programming
- Variables and Data Types
- Loops and Conditional Statements
- Random Number Generation (`rand()`, `srand()`)
- User Input and Output (`cin`, `cout`)

### ▶️ How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Compile the C++ file:
   `g++ number_guessing.cpp -o game`
4. Run the program:
   `.\game.exe`

### 🎓 Learning Outcome
This project helped me practice fundamental C++ concepts and understand how to use random number generation, loops, and conditional statements to build an interactive console-based application.
